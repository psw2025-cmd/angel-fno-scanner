# Level 3 secure relay (PAPER only)

This is a synthetic WebSocket test harness, NOT an authenticated Angel SmartAPI connection. Live mode fails closed. Set PAPER_MODE=1 and LIVE_ORDER_AUTHORITY=0. Run `pip install -r requirements.txt && pytest -q && uvicorn app:app` from relay/. A trusted gateway must authenticate browser sessions, enforce origin and rate limits, and inject x-relay-gateway-secret into the upstream request. Set RELAY_GATEWAY_SECRET only on the relay/gateway, never in frontend code. Browsers cannot set custom WebSocket headers. Never expose Angel credentials or R2 keys to clients. Angel login/TOTP, feed subscription, R2 write endpoint, and actual live-feed receipts remain unimplemented pending secure deployment and verification. Do not publish the relay directly to the internet without the gateway. No order-routing code is present.
