## 2. Overlaps and Duplicates Identified

1. **Defect Tracking Overlap:**
   `AUDIT_AND_DEFECT_REGISTER.md` in root vs the new structured `docs/DEFECT_REGISTER.md`. Root register contains historical batches 3–8. The new `docs/DEFECT_REGISTER.md` will become the permanent authoritative register with standardized D-XX defect IDs, statuses, and linked decision documents.
2. **System Architecture & Overview Overlap:**
   `FRONT.md`, `README.md`, and `SYSTEM_AUDIT_STATUS.md` all describe pieces of the architecture, data flow, and components. These will be consolidated into `docs/ARCHITECTURE.md`.
3. **Coordination Protocols:**
   `docs/CROSS_AGENT_COORDINATION_V1.md` overlaps with `AGENTS.md`. `AGENTS.md` remains the permanent operating contract, while `docs/AGENT_CONTRACT.md` will codify the 16 strict rules for code agents.
