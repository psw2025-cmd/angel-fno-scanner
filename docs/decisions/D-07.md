# Decision: D-07 — Stale Sheet Tabs (TOMORROW_EXPLOSIVE_WATCH and PREMARKET_VS_ACTUAL)

**Defect ID:** D-07  
**Found Date:** 2026-10-05  
**Severity:** LOW  
**Status:** OPEN  

---

## 1. Description
Two auxiliary tabs in the Google Sheet `OPTION_SHEET` have not updated with recent sessions:
- `TOMORROW_EXPLOSIVE_WATCH` header states: `FOR 29-SEP-2026`
- `PREMARKET_VS_ACTUAL` header states: `28-SEP-2026`
Both tabs are approximately 6 days stale relative to current trading sessions.

## 2. Evidence
- Google Sheet export and workbook DNA audit:
  - `TOMORROW_EXPLOSIVE_WATCH!A1` timestamp: `2026-09-29`
  - `PREMARKET_VS_ACTUAL!A1` timestamp: `2026-09-28`
  - Primary tabs (`FORENSIC_LIVE`, `OPTION_PREDICTIONS`, `HEARTBEAT`) reflect recent dates, confirming the core publisher runs while these auxiliary tabs were bypassed or unlinked from the main cycle.

## 3. Impact
- Users viewing auxiliary tabs see outdated signals.
- Confuses manual inspection and audit verification.

## 4. Options Considered
1. **Option A (Recommended):** Integrate `TOMORROW_EXPLOSIVE_WATCH` and `PREMARKET_VS_ACTUAL` into the standard `market_bot` publication cycle in `scanner.py` / `publication.py` with explicit session date stamps.
2. **Option B:** Mark these tabs with a `[LEGACY / UNMAINTAINED]` banner if they are no longer part of active production.
3. **Option C:** Drop the tabs from the consumer workbook.

## 5. Recommended Action
1. Determine whether `TOMORROW_EXPLOSIVE_WATCH` is produced by `angel_prediction_engine.py` pre-close journaling (`journal_pre_close_paper_trades`).
2. If active, ensure the pre-close GitHub Actions cron triggers every weekday at 15:10 IST to refresh the tab.
3. If deprecated, add a banner marking it `LEGACY SNAPSHOT`.

## 6. Open Questions
- Is `TOMORROW_EXPLOSIVE_WATCH` intended to be written only during market pre-close (15:10–15:30 IST), and was skipped due to workflow timeouts or market holidays?
