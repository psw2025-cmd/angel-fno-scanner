# Decision: D-08 — CE_PE_RANK Column C Empty Referenced by Formula Checks

**Defect ID:** D-08  
**Found Date:** 2026-10-05  
**Severity:** MEDIUM  
**Status:** OPEN  

---

## 1. Description
Every data row in the `CE_PE_RANK` worksheet has an empty or unpopulated Column C in the live Google Sheet. The formula in `Formula Checks` for GATE-06 historically checked `COUNTA(CE_PE_RANK!C3:C218)`, which consistently evaluates to 0 or blank, causing false alarms.

## 2. Evidence
- Inspection of `CE_PE_RANK` worksheet structure:
  - Column A: Rank (1 to 200)
  - Column B: Contract Symbol (e.g. `NIFTY26OCT25000CE`)
  - Column C: Blank / empty in live output
  - Column D: Underlying Symbol
  - Column E: Option Type (`CE` or `PE`)
- `docs/formula-checks-contract.md` lines 27–34 explicitly notes:
  "Do not count column C for symbol coverage; column C is the option type (`CE` or `PE`) or blank."
  "GATE-06 observed: `=COUNTA(CE_PE_RANK!A5:A204)&" / 200"`"

## 3. Impact
- Formula checks evaluating Column C fail continuously.
- Visual auditing of `CE_PE_RANK` shows an unpopulated column, creating ambiguity over missing data vs deliberate layout.

## 4. Options Considered
1. **Option A (Recommended):** Align the publisher output in `gainers.py` to write explicit values to Column C (e.g. `CE`/`PE` or Strike) OR eliminate the blank column and update the schema header.
2. **Option B:** Update `Formula Checks` to query Column A (`Rank`) or Column B (`Contract Symbol`), which are guaranteed non-empty for all 200 rows.
3. **Option C:** Do both (A and B).

## 5. Recommended Action
1. Implement Option B immediately: ensure `Formula Checks` checks Column A (`A5:A204`).
2. Audit `gainers.py` publisher mapping to verify if Column C was intended to hold Option Type or Moneyness, and populate it cleanly.

## 6. Open Questions
- What was the original column specification for Column C in `CE_PE_RANK` when the workbook was first drafted?
